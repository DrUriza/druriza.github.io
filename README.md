# TradELATIN

<img src="assets/logo/tradelatin-vr-logo.png" alt="TradELATIN logo" height="70">

TradELATIN is an independent research and engineering program for financial observability, structural market representation, predictive modeling, and risk-controlled autonomous decision architectures.

## Current status

- **C1–C8:** implemented observational pipelines, validated primarily through emulator/synthetic/replay workflows. Live acquisition requires external provider credentials and applicable data access.
- **C9 — Blockchain Financial Networks:** planned / in development.
- **Stacks:** Getting Started Grant application submitted / under review.
- **VR2:** CONVENTIONAL implementation scope; GEOMETRIC and TOPOLOGICAL remain research / expansion.
- **VR3:** deterministic predictive component architecture; release-specific validation evidence is separate from production readiness.
- **VR4:** decision and execution component architecture; SIMULATION, PAPER and gated LIVE modes. No real-capital deployment is claimed.
- **VR5:** intelligence and orchestration layer in development; agent / tool / workflow capabilities are architectural targets.

The existing C1–C8 architecture contains 33 logical endpoints. TradELATIN is not presented as a continuously running public production service. No approval, funding, partnership, endorsement, operational Stacks integration, or completed C9 Stacks implementation is claimed.

## Architecture and authority

The functional pipeline is **VR1 → VR2 → VR3 → VR4**. VR5 is a transversal layer for interaction, explanation and coordination across all four layers. **LLM ≠ Trading Authority**: execution authority, risk controls and execution-state transitions remain in VR4. **Prediction ≠ Execution Authorization**.

VR1 uses Screen / Processing / Connection-Emulator / Integration. VR2–VR4 use Screen / Processing / Integration; fixtures, replay and test datasets belong within Processing / Integration. VR4 execution modes are not separate Emulator repositories.

Explore [Architecture](architecture.html), [VR5](vr5.html), [VR1 HMI evidence](vr1-hmi.html) and [C9 Blockchain Financial Networks](blockchain-networks.html). The supplied posters illustrate architecture; they are not implementation or production evidence.
